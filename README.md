**📊 Data Analytics Task 1 – Data Cleaning & Wrangling**

**Project Overview**
This project focuses on cleaning and preparing a restaurant sales dataset for analysis.
The objective was to perform data wrangling, detect inconsistencies, and create new calculated features for better business insights.

**Steps Performed**

	*Loaded raw dataset
	*Checked dataset structure and data types
	*Identified and handled duplicate records
	*Verified missing values
	*Created new calculated columns:
	*tip_percentage
	*revenue_per_person
	*tip_per_person
	*Prepared a structured Data Dictionary



**Files Included**

	*sales_data.csv → Original dataset
	*cleaned_sales_data.csv → Cleaned dataset
	*Task1_Data_Wrangling.ipynb → Jupyter Notebook
	*Data Dictionary (Google Sheet)

**Key Learnings**

	*Data profiling and cleaning
	*Feature engineering
	*Business-focused data understanding
	*Preparing structured documentation
